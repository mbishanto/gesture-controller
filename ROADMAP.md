- [x] Modular architecture with ES modules
- [x] 10+ gesture recognition
- [x] Settings panel with persistence
- [ ] Unit tests for gesture recognition
- [ ] Performance benchmarks and optimization
- [ ] Keyboard shortcut customization UI

- [ ] Electron desktop companion app
- [ ] System-wide keyboard shortcut support (via native module)
- [ ] Custom gesture training (record your own gestures)
- [ ] Multi-camera support
- [ ] Gesture recording and playback
- [ ] Dark/light theme toggle in settings

## Long-term (6-12 months)

- [ ] WASM-accelerated gesture recognition
- [ ] Machine learning gesture model (TensorFlow.js)
- [ ] WebSocket API for remote control
- [ ] VR/AR hand tracking (WebXR)
- [ ] Mobile app companion
- [ ] Plugin system for custom actions
- [ ] Real-time collaboration features
